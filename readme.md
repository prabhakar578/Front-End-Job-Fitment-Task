📝 Frontend To-Do App – Instructions

📌 Task Overview
You are required to implement the Task Bar functionality in this project. The app should allow users to:

Add new tasks dynamically
 i have added the tasks of list 
Mark tasks as complete

Delete tasks

Persist tasks using localStorage

⚙️ Workflow & Submission Steps
Fork the Repository

Click the Fork button on the provided GitHub repository link to create a copy under your account.

Clone Your Fork

Clone the forked repository to your local machine:

bash
git clone https://github.com/<your-username>/Front-End-Job-Fitment-Task.git

Create a New Branch

Work on a separate branch for clarity:

bash
git checkout -b feature/task-bar
Implement the Task Bar Feature

Complete the missing DOM logic in script.js.

Ensure the task bar works properly with Add, Complete, Delete, and Persistence functionality.

Commit Your Changes

Use meaningful commit messages:

bash
git add .
git commit -m "Implement add and delete task functionality"
Push to Your Fork

Push your branch to your forked repository:

bash
git push origin feature/task-bar
Create a Pull Request (PR)

Go to your fork on GitHub.

Click Compare & Pull Request.

Submit a PR to the original repository.

In the PR description, clearly explain the changes you made.
